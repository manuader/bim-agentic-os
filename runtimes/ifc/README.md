# Isolated IFC evaluator

Python 3.12 worker for the bounded canonical-room compiler adapter and fixed IFC4 evaluation oracle. Install into a repository-local virtual environment with `python -m pip install -r requirements/ifc.txt` (includes pytest because IfcOpenShell EXPRESS validation imports its assertion module). No global Python installation is modified.

Run `python -m unittest discover -s tests/ifc -p 'test_*.py' -v`. A .NET8 SDK is required to generate actual compiler packets; set BIM_DOTNET to an absolute SDK executable if it is not on PATH. Fixtures use owned temporary directories; generated packet inputs stay in ignored `.bim/`.

Use `pwsh -File scripts/evaluate.ps1 -Backend ifc` for default C# compilation and real evaluation. Direct worker invocation requires `python runtimes/ifc/worker.py --request COMPILED_PACKET_JSON --output-dir ABSOLUTE_FRESH_DIRECTORY`; export packets with the CLI's `ifc-export` command. Standard output contains one protocol-version-1 JSON envelope; diagnostic errors use stderr and a nonzero exit code. The worker refuses any existing filename it would write before authoring begins. It writes `room.ifc`, `before.ifc`, `hashes.json`, `benchmarks.json`, `compiled-request.json` and its own transient `room.pending.ifc` in the supplied directory. Caller must supply a fresh isolated fixture directory.

Cross-store recovery ([ADR0007](../../docs/architecture/adr/0007-cross-store-recovery.md) option A): `resize_compiled` retains the adapter packet as `compiled-request.json` beside the IFC before publishing, staging it through `compiled-request.pending.json` (fsync, then `os.replace`). It refuses to stage through a symlink or non-regular file at either name. `python runtimes/ifc/worker.py --receipt ABSOLUTE_IFC_PATH` is read-only: it prints one JSON object `{state, staging_artifact_present, staging_hash}` with the unchanged `BimExecution` state, and exits nonzero on error. Pass that JSON and the retained packet to the CLI `reconcile core-directory receipt.json compiled-request.json`. It replays the Core commit only for the latest one-revision gap and otherwise returns a typed failure code without writing. `clear_staging(path, staging_hash)` removes a crash-left `room.pending.ifc` only when it is a regular file, is not the published IFC, and still holds the bytes the receipt observed. The envelope's eight IFC check IDs cover schema/EXPRESS validation, mesh geometry including opening cuts, hosting, save/reopen, receipts, incremental identity preservation, retry and rollback. Zero worker exit means portable IFC checks passed; full evaluator exit2 still preserves unsupported mandatory native outputs.

Lengths and placements are explicit millimetres. Each observed logical product has a BimIdentity property set mapping its ID to the persisted IFC GlobalId. BimExecution on IfcProject stores operation payload receipts and revision. The resize updates existing wall/space/hosted-window representations in place; rejected staged mutation never publishes a file and retry does not rewrite it. Geometry inspection checks world mesh extents and cut volumes against the actual swept profiles and placements, opening/fill alignment and host containment. Space area is derived from its triangulated volume divided by measured extrusion height.

The C# service now binds existing RoomCompiler snapshots and exact Compiler.Diff to this worker without changing the saved Core schema. Physical UUID bindings are persisted separately from evaluation role labels. Width-only rectangle changes and consecutive committed revisions are supported; doors/windows remain adapter-owned fixture extras. This is not arbitrary BIM-IR execution, native Revit documentation or proof of RVT behavior. No IFC annotations/views/schedules/sheets substitute native deliverables. Native-only values remain null. Read/write metrics count logical observation products and exclude auxiliary IFC entities and extra validation traversals; unavailable metrics stay null. Standalone benchmarks report measured worker phases. See [adapter limits](../../adapters/ifc/Bim.Ifc.Compiler/README.md) and [reproduction](../../docs/ifc.md).

`dependency-licenses.json` records the installed wheel metadata and license-file locations for the pinned closure. IfcOpenShell is LGPL-3.0-or-later; its wheel includes native libraries and Shapely includes GEOS. This approved isolated optional runtime is not vendored or redistributed here; the inventory is provenance, not a complete legal compliance assessment. No Bonsai/GPL extra is installed. Retain the upstream wheels' full license files when distributing dependencies. Upstream IfcOpenShell 0.9.0.post1 EXPRESS rule execution emits a ResourceWarning for its own unclosed IFC4.py source read under unittest; validation still executes and the worker does not suppress it.
