# Isolated IFC evaluator

Python 3.12 worker for the fixed IFC4 evaluation room. Install into a repository-local virtual environment with `python -m pip install -r requirements/ifc.txt` (includes pytest because IfcOpenShell EXPRESS validation imports its assertion module). No global Python installation is modified.

Run `python -m unittest discover -s tests/ifc -p 'test_*.py' -v`. The test creates temporary fixtures exclusively under `.bim/ifc-tests`.

Run `python runtimes/ifc/worker.py --output-dir ABSOLUTE_FRESH_DIRECTORY`. Standard output contains one protocol-version-1 JSON envelope; diagnostic errors use stderr and a nonzero exit code. The worker refuses an existing `room.ifc`. It writes only `room.ifc`, `before.ifc`, `hashes.json`, `benchmarks.json` and its own transient `room.pending.ifc` in the supplied directory. Caller must supply a fresh isolated fixture directory. The envelope's eight IFC check IDs cover schema/EXPRESS validation, mesh geometry including opening cuts, hosting, save/reopen, receipts, incremental identity preservation, retry and rollback. Zero exit means these portable IFC checks passed; it does not establish full Revit Test A/B acceptance.

Lengths and placements are explicit millimetres. Each observed logical product has a BimIdentity property set mapping its ID to the persisted IFC GlobalId. BimExecution on IfcProject stores operation payload receipts and revision. The resize updates existing wall/space/hosted-window representations in place; rejected staged mutation never publishes a file and retry does not rewrite it. Geometry inspection checks world mesh extents and cut volumes against the actual swept profiles and placements, opening/fill alignment and host containment. Space area is derived from its triangulated volume divided by measured extrusion height.

This fixture does not compile arbitrary BIM-IR intents, run the C# incremental compiler, create native Revit documentation, or prove RVT behavior. No fake IFC annotations/views/schedules/sheets are substituted. Native-only values remain null. Read/write metrics count logical observation products and exclude auxiliary IFC entities and extra validation traversals; unavailable metrics stay null. Standalone benchmarks report measured worker phases.

`dependency-licenses.json` records the installed wheel metadata and license-file locations for the pinned closure. IfcOpenShell is LGPL-3.0-or-later; its wheel includes native libraries and Shapely includes GEOS. This approved isolated optional runtime is not vendored or redistributed here; the inventory is provenance, not a complete legal compliance assessment. No Bonsai/GPL extra is installed. Retain the upstream wheels' full license files when distributing dependencies. Upstream IfcOpenShell 0.9.0.post1 EXPRESS rule execution emits a ResourceWarning for its own unclosed IFC4.py source read under unittest; validation still executes and the worker does not suppress it.
